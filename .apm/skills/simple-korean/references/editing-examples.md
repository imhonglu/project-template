# 한국어 표현 편집 예제

## HTML 힌트와 짧은 구 유지

**원문**

```markdown
_<!-- 이 코드를 잘 모르는 독자도 이해할 수 있도록 변경 내용을 쉬운 말로 120자 이내로 요약합니다. -->_
```

**편집**

```markdown
_<!-- 이 코드를 잘 모르는 독자도 이해할 수 있도록 변경 내용을 쉬운 말로 요약. 길이 <= 120자 -->_
```

강조·HTML 주석·독자·요약 목적·상한을 보존했습니다. `요약·초심자·120자`로 줄이면 독자와 요약의 관계가 사라집니다.

글자 수는 이 템플릿의 조건이며 스킬 전체의 길이 제한이 아닙니다.

## 다른 조건은 분리

**원문**

> 운영자 승인 후 삭제합니다. 보존 대상은 삭제하지 않습니다. 파일 크기는 10 MB 미만이어야 합니다.

**잘못 줄인 예**

> 운영자·승인·삭제·보존 대상 제외·10 MB 이하

승인 주체·순서가 흐려졌고 `< 10 MB`가 `<= 10 MB`로 바뀌었습니다.

**편집**

- 운영자 승인 후 삭제
- 보존 대상 삭제 금지
- 파일 크기 < 10 MB

승인 후 삭제라는 순서는 한 항목에, 삭제 예외와 크기 제한은 별도 항목에 남겼습니다.

## 짧지만 다른 뜻인 표현 구분

| 원문                                             | 편집                                   | 바꾸면 안 되는 표현                                |
| ------------------------------------------------ | -------------------------------------- | -------------------------------------------------- |
| 명령을 아직 실행하지 않았습니다.                 | 명령 미실행                            | 실패: 실행한 적이 있다는 뜻이 됨                   |
| 반환값을 수정할 수 있는지는 확인하지 못했습니다. | 반환값 수정 허용 여부 미확인           | 반환값 수정 금지: 없던 금지가 생김                 |
| 연결이 끊기면 일부 기록이 남을 수 있습니다.      | 연결이 끊기면 일부 기록이 남을 수 있음 | 기록 없음 또는 기록이 남음: 가능성이 확정으로 바뀜 |

`최대 크기 근처에서 실패`만으로 `<`와 `<=`를 정하지 않습니다. `적절히 처리합니다`는 실패 시 임시 파일을 삭제한다는 근거가 있을 때만 `실패하면 임시 파일을 삭제합니다`로 바꿉니다.
