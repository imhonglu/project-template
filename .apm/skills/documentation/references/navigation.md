# 탐색 안내

독자가 알고 있는 정보에 따라 안내를 고릅니다.

| 독자의 상태             | 구성                        | 예                               |
| ----------------------- | --------------------------- | -------------------------------- |
| 읽을 주제를 알고 있음   | [목차](#주제로-찾기)        | `설정` · `사용법` · `문제 해결`  |
| 해결할 문제를 알고 있음 | [작업 선택](#상황으로-찾기) | `연결이 실패함 → 연결 문제 해결` |
| 순서대로 수행하면 됨    | 단계별 본문                 | `준비 → 실행 → 확인`             |

아래는 `## 설치`·`## 사용법`·`## 연결 문제 해결` 절이 있는 문서의 탐색 부분입니다. 본문 절의 실제 제목·앵커에 맞춰 문서 앞이나 해당 주제의 시작에 둡니다.

## 주제로 찾기

읽을 주제를 알고 있다면 제목과 위치를 목록으로 연결합니다.

```markdown
## 목차

- [설치](#설치)
- [사용법](#사용법)
- [연결 문제 해결](#연결-문제-해결)
```

## 상황으로 찾기

상황과 읽을 내용의 대응을 나란히 비교할 때는 표를 사용할 수 있습니다.

```markdown
## 작업 선택

| 상황          | 읽을 내용                         |
| ------------- | --------------------------------- |
| 처음 사용함   | [설치](#설치)                     |
| 연결이 실패함 | [연결 문제 해결](#연결-문제-해결) |
```

같은 안내를 짧은 조건·링크 목록으로 표현할 수도 있습니다.

```markdown
## 작업 선택

- 처음 사용한다면 [설치](#설치)부터 진행합니다.
- 연결이 실패하면 [연결 문제 해결](#연결-문제-해결)을 확인합니다.
```

두 형식은 같은 정보를 담은 대체안입니다. 항목의 길이·비교할 정보와 문서의 기존 표현에 맞춰 하나를 고릅니다.

## 실제 문서에 적용

- 단순한 나열은 목록, 반복되는 대응·비교는 표를 검토합니다.
- 링크는 필요한 작업·설명의 시작점으로 연결하고, 해당 전제·검증도 함께 찾을 수 있게 합니다.
- 같은 내용을 안내하는 목차·작업 선택은 하나로 통합합니다. 제목·형식은 문서에 맞게 고르고, 같은 역할의 안내는 문서 안에서 일관되게 표현합니다.
