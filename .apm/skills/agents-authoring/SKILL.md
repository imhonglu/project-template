# 저장소 에이전트 지침 작성·정제

## 근거와 적용 범위

요청 경로의 지침·작업 상태와 관련 근거를 함께 확인합니다. 명령·검증은 스크립트·설정·CI, 사용 안내는 README와 대조합니다. 확보한 근거를 재사용하고 빠진 정보만 추가 조회합니다.

사용자의 선택과 기존 필수 검사·권한·예외를 보존합니다. 바뀐 명령은 실제 정의에 맞춥니다. 정책 충돌은 요청·적용 범위로 풀 수 없을 때만 질문합니다. 문서 정리를 이유로 새 검사나 승인을 만들지 않습니다.

## 정리

| 관찰한 내용                                  | 편집                                         |
| -------------------------------------------- | -------------------------------------------- |
| 여러 경로에 같은 규칙이 반복됨               | 공통 지침에 한 번만 둠                       |
| 특정 경로의 명령·제약이 다름                 | 해당 경로의 지침에 차이와 적용 조건을 둠     |
| README·설정에 이미 있는 사용법·값            | 정본으로 연결하고 작업에 필요한 조건만 남김  |
| 별도로 요청하고 완료할 반복 작업의 상세 절차 | 스킬에 두고 저장소 지침에는 공통 정책만 남김 |

하위 지침은 실제 차이가 있을 때 만듭니다. 명령은 작업 디렉터리·대상·실행 조건을 함께 적습니다.

## 확인

편집 후 작업 상태·변경 내용·관련 검사 결과를 함께 확인합니다. 대표 경로의 규칙·명령·링크를 대조하고, 옮긴 규칙의 범위와 필수 검사·권한·예외가 유지되는지 확인합니다.

저장소의 필수 검증을 따르고, 작성·정적 대조 결과와 실제 실행 결과를 구분해 보고합니다.
