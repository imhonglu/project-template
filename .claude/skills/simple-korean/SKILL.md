# 간결하고 자연스러운 한국어

뜻이 같은 자연스러운 표현 중 더 짧고 바로 읽히는 쪽을 고릅니다. 문장 수·단어 수를 고정하지 않습니다.

## 표현과 형식

- 표현만 수정하면 제목·목록·강조·HTML 힌트와 정보 위치를 유지합니다.
- 제목·항목·힌트는 구·명사형으로, 주체·순서·이유가 필요한 곳은 문장으로 씁니다. 같은 역할끼리 형식을 맞춥니다.
- 같은 개념은 기존 용어 하나로 맞추되 다른 상태·책임은 합치지 않습니다.
- `설정 적용을 진행합니다`는 `설정을 적용합니다`로, 제목이면 `설정 적용`으로 줄입니다.
- 지워도 사실·조건·행동·판단이 같은 문구는 뺍니다. `가능`·`위해`·`진행`처럼 허용·목적·상태를 나타낼 수도 있는 말을 금지어로 일괄 삭제하지 않습니다.

## 조건과 의미

서로 다른 조건·책임·예외는 문장이나 목록으로 나눕니다. 단순 병렬인 `린트·포맷`은 유지하되 `승인 후 삭제`를 `승인·삭제`로 줄여 순서를 숨기지 않습니다.
수치 조건은 대상·단위·비교 방향·경계값 포함 여부가 드러나면 수식으로 씁니다.

| 원문                                                          | 편집                                      |
| ------------------------------------------------------------- | ----------------------------------------- |
| 파일 크기는 10 MB 미만이어야 합니다.                          | 파일 크기 < 10 MB                         |
| 대기 시간은 0밀리초 이상 5000밀리초 이하입니다.               | 0 ms <= 대기 시간 <= 5000 ms              |
| 운영자가 승인한 뒤 삭제합니다. 보존 대상은 삭제하지 않습니다. | 운영자 승인 후 삭제. 보존 대상 삭제 금지. |
| 반환값을 수정할 수 있는지는 확인하지 못했습니다.              | 반환값 수정 허용 여부 미확인              |

다음은 줄인 뒤에도 원문과 같아야 합니다.

- 사실·가정·제안·미확인, 가능성과 확정의 구분
- 부정·금지·필수/선택·승인 주체·예외·완료 시점·소유권
- 수치·단위·상한/하한·경계값 포함 여부
- 식별자·경로·명령·오류 메시지·코드 리터럴·인용문·정해진 명칭

모호한 주체·조건은 제공된 근거에서 찾고, 근거가 없으면 미확인으로 남깁니다. 원문에 없는 보장·금지·이유를 채우지 않습니다.

HTML 힌트·조건 분리·잘못된 축약은 [편집 예제](references/editing-examples.md)로 대조합니다.
