# 스킬 작성·정제

요청·기존 스킬·실제 작업 기록에서 시작 조건, 수행할 일, 산출물과 완료 기준을 찾습니다. 대상 환경의 원본 위치를 확인해 작성하고, 배포 명령은 그 환경의 절차를 따릅니다.

## 남길 규칙

사용자의 명시적 선택·수정·예외와 기존 규칙에서 기본값을 찾습니다. 일반적인 도구 설명보다 **컨벤션·선택 이유·예외 조건**을 남기고, API 상세는 공식 문서로 연결합니다.

- 기본 행동을 바로 쓰고 다른 선택이 필요한 경우에만 관찰 가능한 조건과 행동을 붙입니다.
- 최신 요청이 기존 규칙을 바꾸면 정본을 갱신합니다. 적용 범위로도 충돌을 풀 수 없을 때만 질문합니다.
- 요청·기존 규칙·실제 계약에 근거하지 않은 제한이나 절차는 추가하지 않습니다.
- 행동을 정하지 않는 목적 소개·일반론, 다른 소유자의 규칙, 앞의 내용을 반복하는 요약은 삭제합니다.

예를 들어 “상황에 맞게 나눕니다” 대신 “한 구현에서만 쓰는 도우미는 그 파일에 비공개로 둡니다”처럼 산출물에서 판단할 수 있게 씁니다. 예제에는 선택을 구별할 입력·조건·결과를 남깁니다.

## 정보 배치

| 위치                 | 담을 정보                                                             |
| -------------------- | --------------------------------------------------------------------- |
| `name`·`description` | 소문자·숫자·하이픈으로 쓴 폴더명과 같은 식별자, 선택할 대상·작업·상황 |
| `SKILL.md`           | 공통 조건·기본 절차·판단 기준·완료 조건                               |
| `references/`        | 조건별 상세 예제·실패 대응; 본문에서 읽을 조건과 경로 연결            |
| `scripts/`           | 반복 조회·변환처럼 재사용할 실행 코드와 검증                          |
| `assets/`            | 산출물에 사용할 템플릿·이미지 등 원본                                 |
| `agents/openai.yaml` | Codex의 표시 이름·호출 예시 등 제품별 설정; 작업 규칙은 본문에 유지   |

[스킬 선택에 먼저 제공되는 정보](https://agentskills.io/specification#progressive-disclosure)는 이름·설명입니다. 본문에 같은 사용 시점을 반복하지 않습니다.
절·표·파일은 선택이나 실행에 필요할 때만 둡니다. 짧은 절차는 본문으로 끝내고, 참고 문서·스크립트·UI 설정은 사용하는 작업이 있을 때 추가합니다.

## 경계와 소유권

규칙은 그 결정을 맡는 한 곳에서 관리합니다. 저장소의 경로·명령·필수 검사는 저장소 지침에 두고, 스킬에는 다른 저장소에서도 수행할 작업 절차를 둡니다. 다른 작업의 규칙은 옮기고 필요한 적용 예만 남깁니다.

| 판단할 조건                                                      | 배치                                |
| ---------------------------------------------------------------- | ----------------------------------- |
| 기존 스킬과 다른 독립 요청·절차·산출물·완료 기준이 있음          | 독립 스킬                           |
| 같은 작업에서 특정 도구·환경·실패에만 필요                       | 해당 스킬의 참고 문서               |
| 기존 작업인데 필요한 요청에서 선택되지 않거나 범위 밖에서 선택됨 | 기존 `description`의 대상·상황 수정 |

예를 들어 스킬 내용 작성과 패키지 설치는 각각 완료할 수 있는 작업입니다. 반면 테스트의 유닛·통합·브라우저별 예제는 검증할 계약에 따라 읽는 상세이므로 한 테스트 스킬의 참고 문서로 둡니다.

작업 절차는 스킬 안에서 완결합니다. 대상의 지침·설정·코드는 작업 근거로 읽되, 특정 저장소 문서나 형제 스킬에 절차를 맡기는 필수 호출 체인은 만들지 않습니다. 형제 스킬 상대 링크도 사용하지 않습니다.
이름·경로를 바꾸거나 삭제하면 선택 조건·참고 문서 링크·배포 대상을 함께 갱신합니다.

## 확인

기본값·예외·범위 밖 요청을 대조하고 메타데이터·내부 링크·예제를 검사합니다. 근거 없는 제한·중복 소유자·필수 형제 호출이 없어야 합니다.
행동을 검증할 때는 대표 요청·최소 입력·대상 스킬만 새 세션에 제공하고, 예상 정답·이전 평가 결과는 제외합니다. 산출물·도구 기록으로 판단하며, 효율은 같은 모델·과제·실행 조건의 사용량으로 비교합니다.
선택 검증에서는 스킬명을 지정하지 않고 선택된 스킬·참고 문서를 확인합니다. 구조 검사·행동 평가·선택 검증의 결과를 구분하고 실행하지 않은 항목은 미확인으로 보고합니다.
